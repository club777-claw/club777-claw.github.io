# 실전 홀덤 HUD 설정 가이드 2026

## HUD란 무엇인가

HUD(Heads-Up Display)란 포커 테이블 위에 상대방의 과거 플레이 데이터를 실시간으로 표시해주는 오버레이 도구다. 2026년 현재 온라인 홀덤에서 HUD는 데이터 기반 의사결정의 핵심 도구로, 수천 핸드의 상대 패턴을 한눈에 파악할 수 있게 해준다.

## 필수 HUD 스탯 10가지

### 기본 스탯 (1열 배치 권장)

1. **VPIP** (Voluntarily Put $ In Pot): 자발적 팟 참여율. 정상 범위 18–28% (6-max)
2. **PFR** (Pre-Flop Raise): 프리플롭 레이즈율. 정상 범위 14–22%
3. **3-Bet%**: 쓰리벳 빈도. 정상 범위 6–10%
4. **Fold to 3-Bet**: 쓰리벳에 대한 폴드율. 정상 범위 55–65%

### 포스트플롭 스탯 (2열 배치 권장)

5. **C-Bet Flop%**: 플롭 컨티뉴에이션 벳 빈도. 정상 범위 50–65%
6. **Fold to Flop C-Bet**: 플롭 C-bet에 대한 폴드율. 65% 이상이면 과다 폴드
7. **WTSD%** (Went To Showdown): 쇼다운 도달율. 정상 범위 24–30%
8. **W$SD%** (Won $ at Showdown): 쇼다운 승률. 정상 범위 50–55%

### 고급 스탯 (팝업 또는 3열)

9. **Aggression Factor (AF)**: 공격성 지수 (벳+레이즈)/콜. 정상 범위 2.0–3.5
10. **Steal%**: 스틸 시도율 (CO+BTN+SB). 정상 범위 28–38%

## 최적 HUD 레이아웃 설정법

### 레이아웃 원칙

효과적인 HUD는 3초 이내에 상대 유형을 파악할 수 있어야 한다.

```
[VPIP / PFR / 3Bet]     ← 1열: 프리플롭 성향 즉시 파악
[CBet / FoldCB / WTSD]  ← 2열: 포스트플롭 경향
[AF / Steal / Hands]    ← 3열: 공격성 + 샘플 크기
```

### 색상 코딩 설정

각 스탯에 색상 범위를 지정하면 시각적으로 즉시 판단 가능하다.

- **VPIP**: 초록(18–28) / 노랑(28–35) / 빨강(35+)
- **PFR**: 초록(14–22) / 노랑(22–28) / 빨강(28+)
- **3-Bet**: 초록(6–10) / 노랑(10–14) / 빨강(14+)
- **Fold to 3-Bet**: 초록(55–65) / 노랑(65–75) / 빨강(75+, 익스플로잇 대상)

## 스탯 기반 상대 유형 분류

HUD 데이터를 기반으로 상대를 4가지 유형으로 즉시 분류할 수 있다.

| 유형 | VPIP | PFR | 특징 | 대응 전략 |
|------|------|-----|------|----------|
| 타이트-어그레시브 (TAG) | 18–24 | 16–22 | 강한 핸드만 참여, 공격적 | 블러프 주의, 밸류 타겟 |
| 루즈-어그레시브 (LAG) | 28–35 | 22–30 | 넓은 레인지, 공격적 | 트랩 전략, 콜다운 확대 |
| 타이트-패시브 (니트) | 12–18 | 8–14 | 극소수 핸드, 수동적 | 스틸 확대, 벳에 폴드 |
| 루즈-패시브 (피쉬) | 35+ | 8–15 | 많은 핸드, 콜 위주 | 씬밸류벳 확대, 블러프 축소 |

## 샘플 사이즈 주의사항

HUD 스탯의 신뢰도는 샘플 크기에 직접 비례한다.

| 핸드 수 | 신뢰 가능 스탯 |
|---------|---------------|
| 30–100 | VPIP/PFR만 참고 가능 |
| 100–500 | 3-Bet, C-Bet 참고 가능 |
| 500–1,000 | 대부분 스탯 유효 |
| 1,000+ | 모든 스탯 높은 신뢰도 |

100핸드 미만에서는 VPIP/PFR 외 스탯으로 결정을 내리지 않는 것이 원칙이다.

## FAQ

**Q: HUD란 무엇이며 왜 필요한가요?**  
A: HUD(Heads-Up Display)는 포커 테이블 위에 상대의 과거 플레이 통계를 실시간으로 표시하는 오버레이 도구입니다. 수백~수천 핸드의 데이터를 시각화하여 상대의 플레이 성향을 즉시 파악하고 데이터 기반 의사결정을 할 수 있게 해줍니다.

**Q: 2026년 가장 추천하는 HUD 소프트웨어는 무엇인가요?**  
A: 2026년 기준 Hand2Note가 다이내믹 HUD(포지션·상황별 자동 스탯 전환) 기능으로 가장 진보된 도구입니다. 초보자에게는 UI가 직관적인 DriveHUD 2를, 커스텀 분석이 필요한 중급 이상에게는 PokerTracker 4 또는 Hold'em Manager 3를 추천합니다.

**Q: HUD 스탯은 몇 핸드부터 신뢰할 수 있나요?**  
A: VPIP과 PFR은 약 30~100핸드부터 참고 가능하고, 3-Bet이나 C-Bet 같은 상황별 스탯은 최소 100~500핸드가 필요합니다. 모든 스탯을 높은 신뢰도로 활용하려면 1,000핸드 이상의 샘플이 권장됩니다.

**Q: VPIP과 PFR 수치로 상대를 어떻게 분류하나요?**  
A: VPIP 18~24 / PFR 16~22이면 타이트-어그레시브(TAG), VPIP 28~35 / PFR 22~30이면 루즈-어그레시브(LAG), VPIP 35+ / PFR 15 이하이면 루즈-패시브(피쉬)로 분류합니다. 이 즉시 분류로 기본 대응 전략을 결정할 수 있습니다.

**Q: HUD 사용이 금지된 사이트에서는 어떻게 하나요?**  
A: HUD가 금지된 사이트에서는 수동 노트 시스템을 활용하세요. 상대별로 색상 태그(TAG=파랑, LAG=주황, 피쉬=초록 등)를 지정하고, 주요 핸드 후 텍스트 노트를 남기는 습관을 들이면 HUD 없이도 데이터 기반 플레이가 가능합니다.
